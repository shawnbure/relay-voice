# Security policy

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** flow on the Security tab. Do not disclose vulnerabilities publicly before a fix is available.

Remove phone numbers, message content, access tokens, API keys, provider IDs, and customer data from reports unless essential. Coordinate a secure transfer when sensitive evidence is required.

## Operator responsibilities

Relay handles telephone metadata and message content. Operators must configure authentication, tenant isolation, Telnyx webhook verification, TLS, secret storage, retention, backups, access logging, abuse controls, messaging compliance, and regional privacy requirements.

Rotate a credential immediately if it has ever been committed, logged, pasted into an issue, or shared insecurely. Rewriting Git history is not a substitute for credential rotation.
